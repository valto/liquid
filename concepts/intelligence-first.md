# Intelligence First, Software Second

**Definition.** Establish the ability to understand and fulfill a need before choosing where dedicated software provides a useful optimization.

An intelligent system can attempt a new task using available information and capabilities. Observed demand and operational requirements can then justify deterministic code or another specialized realization.

This is a change in sequencing, not an assertion that intelligence always performs better. Real-time behavior, safety-critical controls and explicit contractual guarantees can justify stable software from the outset.

## Compare fulfillment paths

Existing software, direct intelligent execution and hybrid approaches have different costs, risks and strengths. Choose using meaningful outcomes rather than the novelty of a generation technique.

## A bounded experiment

Start with one capability and preserved evidence. Define accepted results and authority, compare candidate paths, and test whether specialization improves performance while retaining the same meaning and commitments.
