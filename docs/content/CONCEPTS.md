# Core concepts

These concepts describe different parts of the transition. Liquid Software concerns changing implementations; adaptive interfaces concern interaction; information preservation concerns what survives; and decision freedom concerns the authority within which choices can change.

Each definition is a research draft with its own scope, version, relationships and associated papers. The concepts are proposals for examination and testing, rather than normative requirements for every system.

Release v0.2.0 adds a ninth concept, Capability Economics, and revises five related concepts using the expanded economics source. Their earlier public versions remain attributable to v0.1.0.

Release v0.3.0 incorporates the 33-page Economics of Execution v3 source, expands Capability Economics and Adaptive Information Retrieval, clarifies the source-attributed maturity terms and adds an optional capability decision record. Earlier paper editions and concept versions remain retained in the publication history.

The current review candidate adds six concepts developed from the supplied [Continuous Intelligence companion](https://valto.github.io/liquid/whitepapers/continuous-intelligence/): Layered Intelligence Cycles, Meta-Learning, Stability-Aware Evolution, Parallel Realizations, Reasoning Compilation and Outcome Verification. They complement the earlier nine concepts. Learning, release and adoption can happen at different rates; useful adaptation can preserve a familiar experience.
