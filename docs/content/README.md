# Liquid Software

Information provides continuity. Human decisions define the boundaries.

## Reverse the dependency

The digital world has often organized information and activity around what existing software can support. Liquid Software explores the reverse relationship: preserve attributable information, establish meaningful authority and shared semantics, then let interfaces and implementations take shape around actual needs.

## A connected body of work

Liquid Software is both the public entry point and a specific paradigm. Adaptive interfaces, preservation for unknown future value, evolving retrieval and degrees of decision freedom each have independent value. They can be adopted separately and composed when their boundaries fit.

The conceptual framing is supplied by **Valto Loikkanen**. The writing and research are AI-assisted. The work proposes an architectural direction and testable questions; it does not claim that the full vision has been deployed or independently validated.

Start with [Beyond the Constraints of Software](https://valto.github.io/liquid/whitepapers/00-beyond-the-constraints-of-software/), the supplied umbrella paper. The [whitepaper library](https://valto.github.io/liquid/whitepapers/) also contains all sixteen complete research drafts, numbered 00–15.

The [expanded economics paper](https://valto.github.io/liquid/whitepapers/economics-of-execution/) and [Capability Economics](https://valto.github.io/liquid/concepts/capability-economics/) examine cumulative net value, time to value, lifecycle costs and reversible implementation choices.
